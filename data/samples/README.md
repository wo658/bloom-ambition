# 샘플 설명서

해커톤 데모·테스트용 예시 자료. 저작권은 각 제조사에 있어 원본 파일은 레포에 포함하지 않는다.

```bash
./data/samples/download.sh
```

| 파일 | 출처 | 용도 |
|---|---|---|
| `ikea-kallax-2x2-assembly.pdf` | [IKEA 공식](https://www.ikea.com/gb/en/assembly_instructions/kallax-shelving-unit-white__AA-1009450-15-100.pdf) | 메인 데모. 24쪽, 글자 없는 그림 + 부품 콜아웃 + 벽고정 경고 |
| `coway-airmega-150-manual.pdf` | [Sylvane 호스팅](https://www.sylvane.com/cdn/shop/files/owners-manual-coway-airmega-150-bedroom-hepa-air-purifier.pdf) | 국내 제조사 사례. 68쪽 다국어, 필터 교체 파트만 사용 |

## 웹 입력 후보

- Prusa CORE One 노즐 교체 (iFixit, CC BY-NC-SA, 8단계): https://www.ifixit.com/Guide/Prusa+CORE+One+Nozzle+Replacement/182464
- Prusa MK4S 노즐 교체 (공식, 20단계): https://help.prusa3d.com/guide/how-to-replace-the-prusa-nozzle-mk4s-mk3-9s_734750
- 삼성서비스 자가관리 가이드: https://www.samsungsvc.co.kr/solution/111714
